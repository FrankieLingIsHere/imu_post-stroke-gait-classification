How to read the project

  1. Read the result dashboardsThey provide the fastest evidence overview.
  2. Inspect the executed notebooksGitHub renders saved figures and outputs directly; no environment is required just to review the analyses.
  3. Trace every decisionUse the repository wiki, reports, and notebook sequence to follow datasets, split safeguards, and limitations.
  4. Reproduce only when neededLicensed source data and a local environment are required for re-execution, never for simple result review.
Source code, evidence notebooks, and data-access guidance are available in the accompanying GitHub repository.
