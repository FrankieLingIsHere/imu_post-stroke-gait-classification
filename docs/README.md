# Documentation

This folder keeps public, project-level planning and technical requirements.

- `DEEP_LEARNING_DEVELOPMENT_PLAN.md` — staged development plan and decision gates.
- `BASELINE_REQUIREMENTS_AUDIT.md` — requirements traceability for the baseline.
- `FOOT_RMS_ANALYSIS_SPEC.md` — specification for the foot-RMS analysis.

Local Word drafts, search records, and IDE handoff notes are intentionally excluded from public version control. They remain available only in the project owner's local workspace.
