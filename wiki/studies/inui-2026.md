Inui et al. (2026), *Identifying and predicting gait stability metrics in people with stroke in uneven-surface walking using machine learning*, *Scientific Reports* 16:5618. The single strongest study in the review on the [[quality-assessment]] rubric — the only one to satisfy all four criteria at once.

## Key findings

- **Corrected 2026-07-29**: the manuscript's Table 3 previously listed this study's classifier as "Not stated," an extraction error a third `journal-critic` adversarial review caught and a fresh fetch confirmed. The paper compares seven classifiers directly: two "glass-box" models (logistic regression, decision tree) and four "black-box" models (SVC, XGBoost, random forest, kNN), plus sPLS-DA as a sparse variable-selection-and-classification method. A separate regression step (six more models: linear regression, SVR, elastic net, RF, XGBoost, kNN) predicts uneven-surface walking metrics.
- Greater than 95% accuracy on a held-out test set (80/20 split, evaluated across 50 repeated stratified samplings).
- Chronicity: median 62.0 days (subacute). Severity: Fugl-Meyer LE and Berg Balance Scale, both reported — one of only two studies (with [[sun-2025]]) reporting both together.
- Data available on request **and** analysis code in two public GitHub repositories — one of only two included studies (with [[pohl-2022]]) sharing code itself.
- The **only** included study reporting an explicit statistical comparability check between its stroke and healthy groups: no significant differences in age, height, weight, BMI, or sex distribution.
- **Verification-tier correction**: earlier drafts of the manuscript grouped this study with [[hsu-2021]] as abstract-only/access-blocked. That was wrong — the nature.com page redirects to a login wall, but the full text was successfully retrieved via PMC (PMC12891470). This is now corrected throughout the manuscript and here.

- **Flagged 2026-07-30 (fourth `journal-critic` pass)**: the manuscript's Table 3 and Section 5.3 previously discussed this study's lower-back accuracy result without noting that the task itself is uneven-surface walking, not standard overground gait, per this study's own title. Added to Table 3's population field and to Section 5.3 as a task-difference flag distinct from the placement question.
