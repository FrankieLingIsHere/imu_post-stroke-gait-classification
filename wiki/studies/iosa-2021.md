Iosa, M., Capodaglio, E., Pelà, S., Persechino, B., Morone, G., Antonucci, G., Paolucci, S., & Panigazzi, M. (2021). *Artificial neural network analyzing wearable device gait data for identifying patients with stroke unable to return to work*. *Frontiers in Neurology*, 12, 650542. https://doi.org/10.3389/fneur.2021.650542. Verified via a real full-text fetch (Frontiers, open access). Found via the same IEEE Xplore/Scopus supplementary search as [[scheffer-2012]]. One of three studies testing a trunk-region sensor alone (with [[igarashi-2024]] and [[tas-2024]]), and the only included study whose classification target is an occupational-rehabilitation outcome (return-to-work capacity) rather than a diagnostic or severity label.

## Key findings

- Two classification targets from the same single sacral IMU: stroke-versus-healthy (90.9% ANN accuracy vs. 75.8% for a conventional logistic-regression baseline) and, within the stroke group, identifying patients unable to return to work (93.9% ANN vs. 81.8% logistic regression) — both times the ANN outperforms the more conventional statistical comparison run alongside it in the same study, a genuine within-study method comparison rather than only a headline accuracy figure.
- Duration of the double-support phase was the single most important input feature for the return-to-work classification, per the ANN's own feature-importance analysis — a spatiotemporal gait-timing feature, not a raw-signal-derived one.
- This is the only included study using return-to-work status as its outcome label, a distinct severity/function-relevant grouping alongside Table 3's other examples (Fugl-Meyer, discharge ambulation, fall-risk category, Brunnstrom stage) per Section 4.1.3's severity-grouping tally.
- [[quality-assessment]]: validation procedure not clearly described as held-out or cross-validated — the one study among the six newly-assessed that does NOT confirm a clean evaluation design (five of six do). Data available on request per its own Data Availability Statement, though no code shared — one of seven studies in this position. Chronic phase stated but no formal severity scale beyond the return-to-work outcome itself. The one newly-assessed study reporting an explicit age-comparability check (p > 0.05), though not independently tested for sex.
