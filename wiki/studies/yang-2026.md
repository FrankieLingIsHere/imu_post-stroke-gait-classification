Yang, S., Kim, J., Youn, I., Kim, S.-J., & Han, S. (2026). *Classification of physical function using a single IMU during walking in stroke patients*. *Biomedical Engineering Letters*. https://doi.org/10.1007/s13534-026-00591-y. Verified via a real full-text fetch (Springer). **Missing from the manuscript's own reference list**, the same gap found for [[shih-2021]] — cited extensively in-text (Table 3, Table 4, and Section 4.1.3) but has no corresponding entry in the References section, confirmed by a direct search of the full reference list for "Yang." Flagged for manuscript-side follow-up rather than worked around silently. The only one of the six newly-assessed studies on the IC4 pathway rather than IC1 — a single stroke-only population graded by function level, not a stroke-versus-healthy paired comparison, so it is absent from Section 4.1.3's "fifteen studies pair a stroke sample against a genuine healthy control group" list even though it is one of the six studies this same IEEE Xplore/Scopus search added.

## Key findings

- Classifies physical function level (SPPB-defined Low- vs. High-Physical-Function, cutoff score 10) from a single shank-mounted IMU, then directly compares that classification's performance against the same task performed with a full laboratory motion-capture (MoCap) system on the identical participants — a genuine sensor-system head-to-head within one study, not just an IMU-only result.
- Best IMU-based result: Linear Discriminant Analysis, accuracy = 0.91. Best MoCap-based result: XGBoost, accuracy = 0.94 — the single shank IMU comes within 3 percentage points of a full laboratory reference system, the authors' own framing being that this supports the IMU's practical use as a low-burden alternative to MoCap specifically, a narrower and more direct deployment claim than most included studies attempt.
- Six classifiers evaluated under leave-one-out cross-validation, with feature selection (mutual information, top 40 features from descriptive-statistical, gait-related, frequency, and variability feature groups) applied before classification — a more elaborate feature-engineering pipeline than most other single-placement included studies.
- [[quality-assessment]]: participant-level leave-one-out cross-validation confirmed. No code or data availability statement. Severity/function reported via the SPPB-based grading itself, explicitly, though time since stroke (chronicity) is not reported. Control-group matching does not apply in the usual sense, since this is a single stroke population split by function level rather than a stroke-versus-healthy design — a real confound is disclosed instead: cane use differed significantly between the Low-PF and High-PF groups (p = .002), an assistive-device confound distinct from the demographic-matching concern the other five newly-assessed studies are checked against.
