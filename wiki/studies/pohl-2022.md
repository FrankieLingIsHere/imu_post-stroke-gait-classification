Pohl et al. (2022), *Accuracy of gait and posture classification using movement sensors in individuals with mobility impairment after stroke*, *Frontiers in Physiology* 13:933987. This review's only sensor-placement comparison drawn entirely from a real, diagnosed stroke cohort — and the design template for this review's own hands-on classification protocol.

## Key findings

- 85–93% accuracy for a coarse walk/non-walk task, 80–86% for a finer five-class gait-and-posture task.
- Wrist-only input performs substantially worse than ankle-inclusive configurations — a genuine, stroke-specific data point against wrist placement, converging with the wrist-related noisiness this review's own healthy-population mining separately finds on the MAREA dataset (see [[sensor-placement]]).
- The only classical-method study to use a **nested** cross-validation design — the same leakage-conscious protocol this review's own hands-on classification later adopts directly (see [[quality-assessment]] and [[classification-methods]]).
- Code publicly available on GitHub (`StimuLOOP/activity-detection`) — one of only two included studies (with [[inui-2026]]) sharing analysis code itself, not just data.
- Has no healthy comparison group, so it's included via IC4 rather than IC1.
