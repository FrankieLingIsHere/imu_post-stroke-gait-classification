## Six studies added 2026-08-05 (wiki-ingest pass) — the criteria that took Table 4 from 16 to 22 studies

Found via an IEEE Xplore/Scopus supplementary search (per the manuscript's own Section 4.1.5/P129-132), ingested from full-text PDFs after a full wiki-sync pass found this page's headline findings below had never been extended past the original 16. Per-study criterion ratings, verified directly against Table 4:

- **Held-out/CV evaluation**: five of six confirm a clean design — [[scheffer-2012]] (participant-level held-out split), [[shih-2021]] (4-fold CV plus cross-system/cross-dataset external testing), [[tas-2024]] (participant-level 10-fold CV), [[orfanos-2026]] and [[yang-2026]] (each participant-level leave-one-out CV). [[iosa-2021]] is the exception — validation procedure not clearly described as held-out.
- **Code/data availability**: uneven, consistent with the existing pattern below. [[iosa-2021]] shares data on request (no code) — one of seven studies in that position project-wide. The other five newly-assessed studies make no availability statement at all.
- **Chronicity + severity**: none of the six report both together, extending this page's existing "weakest criterion" finding. [[tas-2024]] and [[yang-2026]] report severity/function alone (Brunnstrom stage and SPPB grading respectively) without chronicity. The other four report neither.
- **Control-group matching**: [[iosa-2021]] reports an explicit age-comparability check (p>0.05, not independently tested for sex) and [[orfanos-2026]] recruits an explicitly age-matched control group — both real, disclosed comparability practice, extending this page's "only four studies address it at all" finding to six. [[scheffer-2012]] has the starkest unaddressed gap among all 22 studies, a ~29-year unmatched age difference (51.2y vs 22.6y) with no statistical check. [[shih-2021]] and [[tas-2024]] give bare demographics with no matching statement. [[yang-2026]] is single-population (no comparison group by design), with a different confound self-disclosed instead: cane use differed significantly between its Low- and High-Physical-Function groups (p=.002).

None of these six challenges [[inui-2026]]'s status as the only study satisfying all four criteria at once.

## The four criteria

1. Held-out or cross-validated evaluation, not training-set-only.
2. Code or data availability for independent verification.
3. Chronicity and severity adequately described.
4. Comparison control group explicitly matched or at minimum clearly described.

## Headline findings

**Counts below are pre-2026-08-05, i.e. out of the original 16 studies, not the current 22 — see the new section above for the six added studies' own ratings.** The current manuscript's own aggregate figure (Section 4.1.5/P129): **16 of the 22** assessed studies confirm a held-out or cross-validated evaluation with no qualification. Aggregate recounts for the other three criteria across all 22 were not attempted in this pass — flag for a future check rather than an unverified guess.

- **15 of 16** (of the original 16 only) confirm a held-out or cross-validated evaluation, **[[hsu-2021]]**, **[[rojek-2025]]**, and **[[obrien-2024]]** all among them. **[[sun-2025]] is the exception** — no train/test split or CV described anywhere, and its near-perfect R²=0.999 on 16 participants is best read as an overfitting risk. **[[obrien-2022]]** self-discloses partial data leakage in its own LOSO design.
- Code or data availability is uneven: only **[[pohl-2022]]** and **[[inui-2026]]** share analysis code itself (both via public GitHub). Six more share data or a dataset link without code: [[wang-2021]], [[sun-2025]], [[brasiliano-2026]], [[abdollahi-2024]], [[lee-2025]], and **[[rojek-2025]]**. [[wu-2025]] explicitly restricts its data. **[[obrien-2024]]** states no availability at all, and so does **[[hsu-2021]]** (corrected 2026-07-29 from "not verifiable" — full text is now confirmed accessible and confirms no statement is made).
- Chronicity + severity together: only **[[sun-2025]]** and **[[inui-2026]]** report both. **[[rojek-2025]]** reports chronicity alone (a coarse range, no severity score). Six report neither, **[[obrien-2024]]** and **[[hsu-2021]]** among them.
- Control-group matching: only **[[inui-2026]]** and **[[shin-2022]]** report an explicit statistical comparability check. [[lee-2025]]'s ~37-year unaddressed age gap is the starkest example of the opposite. **[[hsu-2021]]**'s own healthy group spans a 47-year internal range (23.5y young subgroup to 70.5y older subgroup) with no comparability check against the 63.4y stroke group either. **[[rojek-2025]]** and **[[obrien-2024]]** recruited no comparison group at all, so this criterion does not apply to either.

## The one clean sweep

[[inui-2026]] is the only study satisfying all four criteria at once — held-out evaluation, code *and* data available, both chronicity and severity reported, and an explicit statistical matching check.

## Note on [[obrien-2024]] (added to the wiki and the manuscript's Table 4, 2026-07-28)

Confirms a held-out evaluation (nested leave-one-subject-out CV, no self-disclosed leakage this time, unlike [[obrien-2022]]'s own LOSO design), but fails the other three criteria: no code or data availability statement, neither chronicity nor a severity score reported, and no healthy comparison group since it is a stroke-only IC4 design. Also contributes a second honest negative result to this page's running theme — sensor data did not improve the nonambulatory subgroup's outcome prediction over benchmark models, reported directly rather than omitted, alongside [[sun-2025]]'s overfitting risk and [[obrien-2022]]'s leakage.

## Note on [[rojek-2025]] (added to the wiki and the manuscript's Table 4, 2026-07-28)

Confirms a held-out evaluation (70/20/10 train/test/validation split plus k-fold cross-validation, explicitly stated as being to prevent overfitting). Fails code availability (data on request only, no code). Reports only a coarse chronicity range (3 months to 3 years post-stroke, no mean, no severity score at all) — weaker reporting than [[sun-2025]] or [[inui-2026]]'s "both together" standard. No control-group matching statement, since it recruited no control group at all, comparing against literature reference ranges instead. Also the first included/eligible study to compare a classical and a deep learning classifier within one paper on the identical task and population, though it too under-reports: only the CNN gets a full precision/recall/F1 breakdown, and the paper never states which sensor stream produced the features fed to any of the four classifiers, so [[classification-methods]]'s classical-vs-deep-learning gap is narrowed by this study rather than fully closed by it.

## Why a custom checklist, not PROBAST (corrected 2026-07-29)

The manuscript's Section 3.6 cites and positions against PROBAST (Wolff, R. F., Moons, K. G. M., Riley, R. D., Whiting, P. F., Westwood, M., Collins, G. S., Reitsma, J. B., Kleijnen, J., Mallett, S., & PROBAST Group, 2019, *Annals of Internal Medicine*, 170(1), 51-58, https://doi.org/10.7326/M18-1376 — verified via WebSearch + Crossref metadata check, 2026-07-20), the standard validated risk-of-bias tool for prediction-model studies (4 domains: participants, predictors, outcome, analysis; 20 signaling questions).

**A `journal-critic` adversarial review caught a circular justification here**: the manuscript previously explained the choice not to use PROBAST by citing [[avvenuti-2018]]'s threshold-based detection and [[felius-2024]]'s unsupervised autoencoder as tasks that don't map onto PROBAST's domains — but those two studies (plus [[ensink-2023]]) are exempt from **any** rigor assessment at all, PROBAST or the custom checklist alike, since none trains a supervised classifier against a comparison group. Citing the exempted studies as the reason for the assessed studies' tool choice was incoherent. The real reason: the sixteen studies actually assessed (IC1/IC4) span more than one prediction task themselves, mostly stroke-versus-comparison classification, but [[sun-2025]] and [[wu-2025]] instead predict a continuous severity score, a task mix PROBAST's diagnostic-model-oriented signaling questions don't accommodate uniformly. That, not the IC5 exemption, is why a lighter, task-agnostic four-criterion checklist was used instead. A future review narrowed to one task type could apply PROBAST directly. See below for the corrected IC5-exemption reasoning itself, which was also wrong on a separate point.

## IC5-exemption premise corrected (2026-07-29)

The manuscript previously stated IC5-admitted studies are exempt from the four criteria because they "involve neither a trained classifier nor a stroke population by design" — false for two of the three. [[ensink-2023]] includes 10 real stroke participants and [[felius-2024]] includes 107, the largest stroke sample of any included study. Only [[avvenuti-2018]] has no stroke population at all. The actual, narrower reason for the exemption: none of the three trains a **supervised classifier against a comparison group**, which is what the four criteria (validation design, code sharing, chronicity/severity, control-group matching) are built to assess. [[ensink-2023]] validates a threshold-based algorithm and [[felius-2024]] applies an unsupervised variational autoencoder, neither producing the kind of classification result the checklist targets. Both Section 3.6 paragraphs were rewritten in the manuscript to state this correctly.
