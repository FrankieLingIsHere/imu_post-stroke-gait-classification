Nine specific directions now guide the project, several of which are prerequisites for the review's own completion rather than only recommendations for the wider field.

1. **Report explicit control-group matching, and share code not only data** — the two clearest gaps [[quality-assessment]] identifies.
2. **Combine multi-placement and pocket-carried evidence in one stroke cohort** — [[pohl-2022]], [[hsu-2018]], and [[brasiliano-2026]]'s systematic comparisons plus [[shin-2022]] and [[lee-2025]]'s pocket-specific evidence, to date non-overlapping. See [[placement-vs-practicality]].
3. **Check reported feature effects for an age confound before interpreting them as pathology-specific** — following directly from the cadence reversal found in [[voisard-2025]].
4. **Test stroke-vs-healthy and stroke-vs-other-neurological-disorder targets on shared placements in one study** — to establish whether [[hsu-2018]]'s shank-leading result and [[voisard-2025]]/[[felius-dataset]]'s lower-back-leading result genuinely reflect different targets, per [[sensor-placement]]'s open disagreement.
5. **Test whether harmonic-locking and placement-dependent periodicity issues** (discovered on [[marea]]) affect previously published results using frequency-domain step/stride detection without a physiological plausibility check.
6. **Apply a classical and a deep learning classifier to the identical sensor configuration, task, and population** — no included study currently makes this direct, method-matched comparison, per [[classification-methods]]. **Justified explicitly, added 2026-07-22**: worth pursuing because of deep learning's current evidence gap, not despite it. [[wang-2021]] already reached the highest accuracy of any included study using a deep model on raw signal alone, no hand-engineered features — a real ceiling deep learning can reach given clean, sufficient input. The data-efficiency concern is a question of dataset scale, not a fundamental limitation, and this review's own seven-dataset audit shows that scale is growing. Added after the user asked directly how continued deep-learning investment should be justified given Section 5.2's classical-methods-favored verdict — the two are complementary, not contradictory: classical methods are the more plausible *near-term* choice on current evidence, deep learning remains worth testing properly before being ruled out. **Narrowed, 2026-07-28**: a dedicated literature search aimed squarely at this gap (see `log.md`) found one real, method-matched candidate, [[rojek-2025]] — SVM, Random Forest, k-NN, and CNN all trained on the identical 120-patient stroke population and identical task, CNN highest at 91.88%, classical methods close behind (SVM 89.91%). This is genuine partial progress on this recommendation, not a null result, but two reporting gaps in that paper (unclear which sensor stream produced the classifier inputs, and no per-classifier precision/recall/F1 breakdown for the three classical models) mean a fully clean, unambiguous method-matched comparison still doesn't exist. **Softened in the manuscript, same day**: Section 7's item now reads "replicate and extend Rojek et al.'s (2025) comparison with fully reported sensor placement and a complete precision, recall, and F1 breakdown," not "no study does this," matching this page's own framing.
7. **Exploit the severity and progression measures this review's own hands-on-mined datasets already contain but don't yet use for classification** — [[voisard-2025]]'s per-trial Fugl-Meyer Lower Extremity and Timed-Up-and-Go scores, and [[felius-dataset]]'s longitudinal two-timepoint subset, both currently limited to the binary healthy-versus-stroke comparison. A gap the manuscript's own Section 4.2.6 names but, until this addition, never carried into Section 7's recommendations.

8. **Develop age as a parallel endpoint before using it in the stroke decision** — the current Voisard interaction audit does not establish a robust group-specific age slope after correction, and Felius lacks public age metadata. The next steps are continuous age regression, age-overlap reporting, age- and sex-matched external recruitment, and a comparison of age-adjusted versus unadjusted baselines. An age-to-stroke cascade or shared multi-task model should wait until those checks are passed. See [[age-and-stroke-gait]].

The first continuous regression comparison is now complete. The engineered-feature Ridge model outperformed the Inception-style regressor on healthy Voisard age prediction, so future work should prioritize age-balanced recruitment and better labels before expanding the age network. The full Voisard release has broad age coverage, but its extra age range comes from neurological and orthopedic cohorts that cannot be treated as additional stroke labels.

The next audit compared raw gait, age-residualized gait, age-only and gait-plus-age baselines. Age alone was predictive in the current imbalanced subset, but gait-plus-age did not improve AUROC over gait alone. This makes age-matched external validation more important before any age-conditioned architecture is considered.

9. **Run a frozen external validation before expanding the model** — RevalExo is the best currently identified public stress-test candidate because it contains lower-body IMUs from stroke and healthy participants, but its sample is small, its protocol differs, and its public README does not provide complete participant-level age metadata. Use it only after schema inspection and channel mapping. A new age-complete, age- and sex-matched cohort remains the real validation requirement. See [[external-validation-cohort]].
